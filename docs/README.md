# 문서

이 블로그를 고치거나 확장할 때 참고하는 판단 기준을 모아 둔 곳이다.
코드에서 읽어낼 수 없는 것 — 왜 그렇게 골랐는지 — 만 남긴다.

| 문서 | 담고 있는 것 | 언제 읽나 |
|---|---|---|
| [DESIGN.md](./DESIGN.md) | 브랜드 톤, 정보 구조, 색·타이포·간격 토큰, 접근성과 반응형 기준 | 화면을 새로 만들거나 기존 화면의 시각 언어를 바꿀 때 |
| [SEO.md](./SEO.md) | 검색 노출 사고 2건의 진단과 대응 근거, 반복하지 말 것, 배포 후 절차 | 라우트·링크 구조·메타데이터·sitemap을 건드릴 때 |

설치와 실행 방법은 루트 [README.md](../README.md)에 있다.

## 문서를 고칠 때

- 두 문서 모두 맨 위에 `Source of truth` 블록이 있다. 내용을 고치면 `Last refreshed`를 함께 갱신한다.
- 라우트를 추가하거나 없애면 `DESIGN.md`의 `Core routes/screens`를 갱신한다. 실제 라우트와 어긋나면 문서가 아니라 방해물이 된다.
- 검색 관련 판단은 결론만 적지 않고 **근거와 측정값**을 남긴다. `SEO.md`의 도달성 계산이 그 예다. 숫자가 없으면 다음 사람이 같은 조사를 처음부터 다시 한다.
